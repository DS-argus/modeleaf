# Theme palette attributions

The application uses small semantic color subsets from these established themes:

- Catppuccin Mocha — Catppuccin project, MIT license.
- Tokyo Night — enkia/tokyo-night-vscode, MIT license.
- Gruvbox — morhetz/gruvbox, MIT license.
- Nord — Arctic Ice Studio, MIT license.

Only application chrome uses these palettes. PDF page content is never recolored.
